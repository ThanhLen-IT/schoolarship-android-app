# Backend integration

The original connection fixes are included in this branch. See
[MOBILE_COMPLETION.md](MOBILE_COMPLETION.md) for the final feature scope, backend
requirements, build commands and validation boundaries. Real backend responses
replace UX sample records; mutations only show success after a successful API reply.

Auth, scholarship search/details/bookmarks, profile, ranking, community posts/likes/
comments, verification PDFs and password reset remain connected. The completion
branch additionally implements avatar uploads, mentoring applications/progress,
private CV access, chat, notifications, support and account closure.
